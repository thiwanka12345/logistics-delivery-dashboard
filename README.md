# 🚛 Logistics Operations & Delivery Performance Dashboard

An end-to-end interactive **Logistics & Delivery Performance Dashboard** built using **Python, Streamlit, Pandas, and Plotly**. 

This application tracks **62,000+ shipments** across multiple regions, warehouses, and vehicle types to provide real-time KPIs, dynamic filtering, and actionable insights.

---

## 📊 Key Features

- **Real-Time KPIs:** Dynamic metrics for On-Time Delivery Rate, Avg Transit Time, Avg Shipping Cost, and Customer Ratings.
- **Interactive Slicers:** Instant filtering by Year, Region, Warehouse, and Vehicle Type.
- **Automated Insights:** Real-time alert boxes identifying route bottlenecks, high-fuel vehicles, top revenue drivers, and delivery delays.
- **Advanced Analytics:** 
  - Monthly Shipment Volume Trends
  - Route Bottleneck Tracking (e.g., identifying delays on specific routes)
  - Revenue Breakdown by Product Category
  - Fuel Cost Analysis by Vehicle Type

---

## 🛠️ Tech Stack

- **Language:** Python
- **Dashboard Framework:** Streamlit
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Plotly Express
